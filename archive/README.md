Ils précèdent le dataset unifié et ne servent plus au pipeline courant. Ne pas utiliser leurs scores pour
comparer les modèles actuels. Aucun contenu personnel n'a été supprimé.
Les scripts sont conservés comme historique ; leurs anciens chemins ne sont plus valides.
