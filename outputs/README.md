# Résultats

- `experiments/<campagne>/` : configurations, prédictions et scores du stream 2, non versionnés.
- `backtest_<modele>.csv` : sortie de l'évaluation simple.
- `output_<groupe>.csv` : CSV de rendu final.

Les anciens rapports et figures basés sur les CSV sont dans `archive/legacy_csv/outputs/`.
Ne pas mélanger leurs scores avec ceux du dataset final.
